# Media Wave Technologies - Institutional Partnerships & Platform

Official Web Platform for **Media Wave Technologies** — Bridging Technology, Education, and Industry through modern software solutions, college MoUs, technical workshops, bootcamps, and live engineering projects.

## 📁 Repository Structure

```
media wave web/
├── frontend/                     # React + Vite Client Application
│   ├── public/                   # Static images, logos, workshop assets
│   ├── src/
│   │   ├── components/           # UI components, modals, feedback system
│   │   ├── data/                 # Mock database, workshops, MoUs, reviews
│   │   ├── pages/                # Page routes (Home, Workshops, About, etc.)
│   │   ├── App.jsx
│   │   └── main.jsx
│   ├── package.json
│   └── vite.config.js
└── README.md
```

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation & Run
```bash
# Navigate to frontend folder
cd frontend

# Install dependencies
npm install

# Start local development server
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.
